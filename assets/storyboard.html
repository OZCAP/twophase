Style guide

Colour = meaning

Read, allowed: always calm and moving
Write, waits for a human
Admin, destructive, never
The shield / brand
Night background, so capsules glow

Motion language

  • Queries are capsules on a wire. Keep the metaphor in every scene.
  • Springs for UI (stiffness about 300–400), linear for travel
  • Stops and stamps get a hit-stop of 60–80 ms
  • No more than one main motion at a time; captions land last

Type & frame

  • Inter / system sans for captions; mono only for SQL
  • Captions sit in the bottom third, at most 7 words, readable muted
  • 9:16 cut: stack the wire vertically (agent on top, database below), with the phone full-screen in scenes 07–08

Build

  • Fastest path: Remotion (React), reusing the app's real components and colours
  • Or Rive / After Effects with Lottie export for the web
  • Real UI shots: the PWA's approval card and notification for scenes 07–08
